La caja se maneja por completo con el teclado y el lector de códigos de barras. Presione **?** o haga clic en el ícono de teclado para mostrar la lista.

![La ventana Atajos de teclado](shot:pos-shortcuts)

| Tecla | Acción |
| --- | --- |
| **F1** | Abrir la ayuda |
| **F2** | Buscar productos / escanear |
| **F4** | Elegir cliente |
| **F6** | Poner la venta en espera |
| **F8** | Descuentos |
| **F9** | Ventas en espera |
| **F12** o **Ctrl + Enter** | Cobrar |
| **↑ ↓** | Seleccionar una línea del carrito |
| **+ −** | Cambiar la cantidad de la línea seleccionada |
| **Supr** | Quitar la línea seleccionada |
| **Esc** | Cerrar la ventana abierta |
| **?** | Mostrar los atajos |

> **Consejo:** después de cada acción, el cursor vuelve al campo de búsqueda: puede escanear el siguiente artículo de inmediato.

> **Consejo:** las teclas **+**, **−**, **?**, **Supr** y las flechas no funcionan mientras escribe en un campo. Las teclas F funcionan en toda la pantalla de caja.
