Después de iniciar sesión, el personal de ventas llega a la pantalla de caja. Tiene tres zonas:

- **La barra superior**: la tienda, la caja, el turno y los botones de acceso rápido.
- **Los productos** (a la izquierda): la búsqueda, las categorías y las fichas de productos.
- **El carrito** (a la derecha): el cliente, el vendedor, los artículos, los totales y el botón **Cobrar**.

![La pantalla de caja](shot:pos-overview)

Una venta se hace siempre en el mismo orden:

1. [Agregue los productos](topic:pos-sell) al carrito.
2. [Elija el cliente](topic:pos-customer), si hace falta.
3. [Aplique los descuentos](topic:pos-discounts), si hace falta.
4. Haga clic en **Cobrar** (F12).
5. [Registre el pago o los pagos](topic:pos-payment) y luego haga clic en **Completar venta**.
6. [Entregue el recibo](topic:pos-receipt) y el cambio.

## La barra superior

| Elemento | Para qué sirve |
| --- | --- |
| Nombre de la tienda | Recuerda en qué tienda está trabajando. |
| Lista de cajas | Elige la caja y la sucursal de este puesto. La elección se guarda en el dispositivo. |
| **Abrir turno** / **SH-000004 · Abierto** | Abre el turno de caja, o muestra el turno en curso (vea [Abrir un turno](topic:shifts-open)). |
| **Abrir cajón** | Abre el cajón sin venta, con un motivo. Visible cuando el turno está abierto. |
| **Registrar entrada** / **Registrar salida** | Registra sus horas. Visible si su cuenta está vinculada a una ficha de empleado. |
| **En línea** / **Sin conexión** | Estado de la conexión. Un clic abre las [ventas sin conexión](topic:offline-sync). |
| **Ventas en espera** | Los [carritos apartados](topic:pos-held-carts) (F9). |
| Ícono de teclado | Los [atajos de teclado](topic:pos-shortcuts). |
| **?** | Esta ayuda (F1). |
| **Devoluciones** | [Devolución o cambio](topic:returns-pos). Visible para las personas autorizadas a reembolsar. |
| **Administración** | Abre la administración (propietario, administrador, gerente). |
| Campana | Las [notificaciones](topic:notifications). |
| **EN FR HT ES** | El [idioma](topic:language) de este dispositivo. |
| Escudo | [Seguridad de la cuenta](topic:account-security). |
| Flecha de salida | **Cerrar sesión**. |

> **Consejo:** cierre sesión siempre antes de dejar la caja a un compañero. De lo contrario, sus ventas se registrarán a su nombre.

> **Consejo:** si la tienda lo exige, la caja se niega a vender mientras el turno no esté abierto.
