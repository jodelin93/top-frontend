## Sell a gift card

1. Click **Gift card** under the cart.
2. In **Sell a gift card**, type the **Amount** (at least 1.00).
3. If you have a pre-printed card, scan its code into **Card code (optional)**. Otherwise, leave it empty: a code will be created.
4. Click **Add to the sale**, then check out as usual.
5. After the sale, the **Gift cards issued — give the codes to the customer** box shows the code. Give it to the customer.

![The Gift cards window](shot:pos-gift-card-dialog)

> **Warning:** a card code has **12 to 32 characters**, letters and digits only, with **at least one letter and at least one digit**. Otherwise the message "A gift card code has 12 to 32 characters, with letters and digits" appears.

> **Warning:** the full code is shown only once. A gift card has no tax and no discount; it can only be sold online and cannot be put on hold.

## Pay with a gift card

1. In the **Payment** window, click **Gift card**.
2. Scan or type the card code.
3. Click **Check balance**. The available balance appears.
4. Check the suggested amount, then click **Add**.
5. If the card does not cover everything, add another payment for the rest.

> **Tip:** "This gift card can't be used" means the card is unknown, not active yet or expired. How long cards stay valid is set in [General settings](topic:settings-general).

The **Check a balance** part of the **Gift cards** window gives a card's balance without a sale: type the code and click **Check balance**.
