You can run the till entirely with the keyboard and the barcode scanner. Press **?** or click the keyboard icon to show the list.

![The Keyboard shortcuts window](shot:pos-shortcuts)

| Key | Action |
| --- | --- |
| **F1** | Open help |
| **F2** | Search products / scan |
| **F4** | Choose customer |
| **F6** | Hold the cart |
| **F8** | Discounts |
| **F9** | Held carts |
| **F12** or **Ctrl + Enter** | Charge |
| **↑ ↓** | Select a cart line |
| **+ −** | Change the quantity of the selected line |
| **Delete** | Remove the selected line |
| **Esc** | Close the open window |
| **?** | Show these shortcuts |

> **Tip:** after each action, the cursor goes back to the search field: you can scan the next item right away.

> **Tip:** the **+**, **−**, **?**, **Delete** and arrow keys do not work while you are typing in a field. The F keys work anywhere on the till screen.
