## Check the reconciliation

Reconciliation checks that every figure matches the source records: sale lines, payments, stock movements, returns and refunds.

1. At the bottom of the report list, click **Reconciliation**.
2. Choose the period and, if needed, the branch.
3. A green banner shows **Everything reconciles for … sale(s) in this period**.
4. Each passed check has a green check mark.

![Reconciliation](shot:reports-reconciliation)

If a check fails, it has a red cross, and a table lists each record involved (**Expected**, **Found**, **Detail**).

> **Warning:** a discrepancy must be reviewed by a manager. Note the reference shown and open the sale or return involved.

## Print the daily summary

The **Daily summary (PDF)** sums up the last day of the chosen period (today by default).

1. Choose the branch if needed.
2. At the bottom of the report list, click **Daily summary (PDF)**.
3. The PDF downloads: print it or file it.
