1. Open **Admin** > **Returns**.
2. The list shows each credit note: number, date, original sale, reason, amount, and status.
3. Filter by status: **Refunded**, **Refund pending**, or **Refund failed**.
4. Click **New return** to make a return from the admin area: the window is the same as at the till (see [Make a return](topic:returns-pos)).
5. Click a credit note to review it or **Print** it.

![The return list](shot:admin-returns)

> **Tip:** a card refund can stay **Refund pending** while the bank responds. If it fails, click **Retry card refund**, or refund another way.

> **Tip:** from a sale's details (**Sales** page), the **Return items** button opens the return for that sale directly.
