Ou ka kontwole tout kès la ak klavye a ak lektè kòd ba a. Peze **?** oswa klike sou ikòn klavye a pou wè lis la.

![Fenèt Rakousi klavye a](shot:pos-shortcuts)

| Touch | Aksyon |
| --- | --- |
| **F1** | Ouvri èd la |
| **F2** | Chèche pwodui / eskane |
| **F4** | Chwazi kliyan |
| **F6** | Mete panye a ann atant |
| **F8** | Rabè |
| **F9** | Panye ann atant |
| **F12** oswa **Ctrl + Enter** | Touche |
| **↑ ↓** | Chwazi yon liy nan panye a |
| **+ −** | Chanje kantite liy ki chwazi a |
| **Delete** | Retire liy ki chwazi a |
| **Esc** | Fèmen fenèt ki louvri a |
| **?** | Montre rakousi sa yo |

> **Konsèy:** apre chak aksyon, kisè a tounen nan chan rechèch la: ou ka eskane pwochen atik la touswit.

> **Konsèy:** touch **+**, **−**, **?**, **Delete** ak flèch yo pa mache pandan w ap tape nan yon chan. Touch F yo mache toupatou sou ekran kès la.
