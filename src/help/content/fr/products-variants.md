Avant de créer des variantes, vérifiez vos attributs (Taille, Couleur…) avec le bouton **Attributs** en haut de la page **Produits**. Chaque attribut a un nom, un code et une liste d'options séparées par des virgules.

## Gérer les variantes

1. Sur la ligne d'un produit variable, cliquez sur l'icône **Variantes** (les calques).
2. La fenêtre **Variantes de …** liste chaque variante : attributs, SKU, code-barres, prix, coût, stock et statut.
3. Pour ajouter une variante, cliquez sur **Ajouter une variante**, remplissez la ligne puis validez.
4. Pour modifier une variante, cliquez sur son crayon.

## Créer plusieurs variantes d'un coup

1. Cliquez sur **Générer à partir des attributs**.
2. Cliquez sur les valeurs voulues pour chaque attribut (elles deviennent bleues).
3. Saisissez le **Prix des nouvelles variantes** et, si vous le connaissez, le **Coût unitaire**.
4. Cliquez sur **Aperçu** pour voir les combinaisons, puis sur **Créer les variantes**.

> **Astuce :** chaque combinaison des valeurs choisies devient une variante ; les combinaisons qui existent déjà sont ignorées.

## Ajouter des codes-barres à une variante

Une variante peut avoir plusieurs codes-barres (ancien et nouvel emballage, par exemple).

1. Dans la fenêtre des variantes, cliquez sur l'icône **Codes-barres** (les barres verticales).
2. Scannez ou tapez le code dans **Scannez ou saisissez un code-barres**.
3. Cliquez sur **Ajouter**. La corbeille retire un code.

> **Attention :** un code-barres ne peut appartenir qu'à une seule variante. Scanner n'importe lequel de ses codes retrouve la variante à la caisse.
