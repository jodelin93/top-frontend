Les clients gagnent des points à chaque achat et peuvent les utiliser pour payer à la caisse. Les règles se règlent dans [Programme de fidélité](topic:settings-loyalty).

Pour corriger un solde (erreur, geste commercial) :

1. Ouvrez la fiche du client, onglet **Détails**, rubrique **Points de fidélité**.
2. Saisissez le nombre de points à ajouter (ex. 50) ou à retirer (ex. -50).
3. Saisissez le **Motif (obligatoire)**.
4. Cliquez sur **Ajuster**.

> **Attention :** les points valent de l'argent. Seules les personnes qui peuvent ajuster les comptes clients (propriétaire, administrateur, gérant) les modifient ; pour les autres, la fenêtre **Approbation du gérant requise** s'ouvre. Chaque ajustement est journalisé.
