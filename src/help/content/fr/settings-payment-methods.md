1. Ouvrez l'onglet **Modes de paiement**.
2. Cliquez sur **Nouveau mode de paiement**, ou sur le crayon d'un mode existant.
3. Choisissez le type : espèces, carte, paiement mobile (MonCash), virement bancaire, avoir…
4. Indiquez si le mode **Ouvre le tiroir-caisse** et s'il **Nécessite une référence** (numéro de transaction MonCash par exemple).
5. Enregistrez.

![L'onglet Modes de paiement](shot:settings-payment-methods)

> **Astuce :** un mode inactif disparaît de la caisse mais reste dans l'historique des ventes. Le nom affiché à la caisse est celui saisi ici.
