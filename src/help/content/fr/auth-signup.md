Sur certains serveurs, la page de connexion propose **Nouveau ? Créer une boutique**. Cette page crée un nouveau magasin dont vous devenez le **propriétaire**.

![Page de création d'une boutique](shot:auth-signup)

1. Sur la page de connexion, cliquez sur **Créer une boutique**.
2. Saisissez le **Nom du magasin**.
3. Saisissez votre **Prénom**, votre **Nom**, votre **E-mail** et un **Mot de passe** (au moins 8 caractères).
4. Vérifiez la **Devise** principale (code à 3 lettres, par exemple USD ou HTG).
5. Cliquez sur **Créer la boutique**.

L'application prépare pour vous une succursale, une caisse et les modes de paiement Espèces et Carte. Vous arrivez ensuite dans l'application, connecté comme propriétaire.

> **Astuce :** si vous avez déjà un compte (dans un autre magasin), saisissez la même adresse et le même mot de passe : le nouveau magasin est ajouté à votre compte. Si ce compte a la double authentification, le code est demandé. Vous passerez ensuite d'un magasin à l'autre dans **Sécurité du compte** (voir [Invitations et changement de magasin](topic:account-invitations)).

> **Attention :** si le message « L'inscription n'est pas disponible sur ce serveur » s'affiche, la création de magasins est fermée. Demandez un compte à votre administrateur.

Étapes suivantes conseillées :

1. Complétez les [Réglages généraux](topic:settings-general) et les [Informations de l'entreprise](topic:settings-business).
2. Vérifiez le [taux de change](topic:settings-exchange-rate).
3. Créez vos [produits](topic:products-create) ou [importez-les](topic:products-import).
4. [Ajoutez votre personnel](topic:users-invitations).
