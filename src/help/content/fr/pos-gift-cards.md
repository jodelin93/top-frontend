## Vendre une carte cadeau

1. Cliquez sur **Carte cadeau** sous le panier.
2. Dans **Vendre une carte cadeau**, tapez le **Montant** (au moins 1,00).
3. Si vous avez une carte pré-imprimée, scannez son code dans **Code de la carte (facultatif)**. Sinon, laissez vide : un code sera créé.
4. Cliquez sur **Ajouter à la vente**, puis encaissez normalement.
5. Après la vente, le cadre **Cartes cadeaux émises — remettez les codes au client** affiche le code. Remettez-le au client.

![La fenêtre Cartes cadeaux](shot:pos-gift-card-dialog)

> **Attention :** un code de carte comporte **12 à 32 caractères**, uniquement des lettres et des chiffres, avec **au moins une lettre et au moins un chiffre**. Sinon le message « Un code de carte cadeau comporte 12 à 32 caractères, avec des lettres et des chiffres » s'affiche.

> **Attention :** le code complet n'est affiché qu'une seule fois. La carte cadeau n'a ni taxe ni remise ; elle se vend seulement en ligne et ne peut pas être mise en attente.

## Payer avec une carte cadeau

1. Dans la fenêtre **Paiement**, cliquez sur **Carte cadeau**.
2. Scannez ou tapez le code de la carte.
3. Cliquez sur **Vérifier le solde**. Le solde disponible s'affiche.
4. Vérifiez le montant proposé, puis cliquez sur **Ajouter**.
5. Si la carte ne couvre pas tout, ajoutez un autre paiement pour le reste.

> **Astuce :** « Cette carte cadeau ne peut pas être utilisée » veut dire que la carte est inconnue, pas encore active ou expirée. La durée de validité des cartes se règle dans [Réglages généraux](topic:settings-general).

La partie **Vérifier un solde** de la fenêtre **Cartes cadeaux** donne le solde d'une carte sans vente : tapez le code et cliquez sur **Vérifier le solde**.
