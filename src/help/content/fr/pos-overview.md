Après la connexion, le personnel de vente arrive sur l'écran de caisse. Il comporte trois zones :

- **La barre du haut** : le magasin, la caisse, la session et les boutons d'accès rapide.
- **Les produits** (à gauche) : la recherche, les catégories et les fiches produits.
- **Le panier** (à droite) : le client, le vendeur, les articles, les totaux et le bouton **Encaisser**.

![L'écran de caisse](shot:pos-overview)

Une vente se fait toujours dans le même ordre :

1. [Ajoutez les produits](topic:pos-sell) au panier.
2. [Choisissez le client](topic:pos-customer), si besoin.
3. [Appliquez les remises](topic:pos-discounts), si besoin.
4. Cliquez sur **Encaisser** (F12).
5. [Enregistrez le ou les paiements](topic:pos-payment), puis cliquez sur **Finaliser la vente**.
6. [Remettez le reçu](topic:pos-receipt) et la monnaie.

## La barre du haut

| Élément | À quoi il sert |
| --- | --- |
| Nom du magasin | Rappelle dans quel magasin vous travaillez. |
| Liste des caisses | Choisit la caisse et la succursale de ce poste. Le choix est gardé sur l'appareil. |
| **Ouvrir la session** / **SH-000004 · Ouverte** | Ouvre la session de caisse, ou affiche la session en cours (voir [Ouvrir une session](topic:shifts-open)). |
| **Ouvrir le tiroir** | Ouvre le tiroir sans vente, avec un motif. Visible quand la session est ouverte. |
| **Pointer l'arrivée** / **Pointer la sortie** | Enregistre vos heures. Visible si votre compte est lié à une fiche employé. |
| **En ligne** / **Hors ligne** | État de la connexion. Un clic ouvre les [ventes hors ligne](topic:offline-sync). |
| **Paniers en attente** | Les [paniers mis de côté](topic:pos-held-carts) (F9). |
| Icône clavier | Les [raccourcis clavier](topic:pos-shortcuts). |
| **?** | Cette aide (F1). |
| **Retours** | [Retour ou échange](topic:returns-pos). Visible pour les personnes autorisées à rembourser. |
| **Administration** | Ouvre l'administration (propriétaire, administrateur, gérant). |
| Cloche | Les [notifications](topic:notifications). |
| **EN FR HT ES** | La [langue](topic:language) de cet appareil. |
| Bouclier | [Sécurité du compte](topic:account-security). |
| Flèche de sortie | **Se déconnecter**. |

> **Astuce :** déconnectez-vous toujours avant de laisser la caisse à un collègue. Sinon, ses ventes seront enregistrées à votre nom.

> **Astuce :** si le magasin l'exige, la caisse refuse de vendre tant que la session n'est pas ouverte.
