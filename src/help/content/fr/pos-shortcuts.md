La caisse se pilote entièrement au clavier et au lecteur de codes-barres. Appuyez sur **?** ou cliquez sur l'icône clavier pour afficher la liste.

![La fenêtre Raccourcis clavier](shot:pos-shortcuts)

| Touche | Action |
| --- | --- |
| **F1** | Ouvrir l'aide |
| **F2** | Rechercher des produits / scanner |
| **F4** | Choisir le client |
| **F6** | Mettre le panier en attente |
| **F8** | Remises |
| **F9** | Paniers en attente |
| **F12** ou **Ctrl + Entrée** | Encaisser |
| **↑ ↓** | Sélectionner une ligne du panier |
| **+ −** | Modifier la quantité de la ligne sélectionnée |
| **Suppr** | Retirer la ligne sélectionnée |
| **Échap** | Fermer la fenêtre ouverte |
| **?** | Afficher les raccourcis |

> **Astuce :** après chaque action, le curseur revient dans le champ de recherche : vous pouvez scanner l'article suivant tout de suite.

> **Astuce :** les touches **+**, **−**, **?**, **Suppr** et les flèches ne marchent pas pendant que vous tapez dans un champ. Les touches F marchent partout sur l'écran de caisse.
