Pour vendre du riz, du sucre, du tissu ou du carburant, créez d'abord une unité avec décimales.

1. Sur la page **Produits**, cliquez sur **Unités**.
2. Cliquez sur **Nouvelle unité**.
3. Saisissez le **Nom** (ex. Kilogramme) et le **Code** (ex. kg).
4. Cochez **Autorise les quantités décimales (ex. 1,25 kg)** et choisissez le nombre de **Décimales**.
5. Cliquez sur **Enregistrer l'unité**.

Ensuite, dans la fiche du produit :

1. Choisissez cette unité dans **Unité de mesure**. Le prix saisi devient le prix par unité (par kilo, par mètre…).
2. Si une balance imprime des étiquettes, saisissez son code article dans **PLU (code balance)**.
3. Enregistrez le produit.

> **Astuce :** à la caisse, le caissier saisit la quantité pesée (ex. 1,250 kg). Les étiquettes de balance (codes-barres commençant par 20 à 29) sont lues automatiquement si elles sont configurées (voir [Étiquettes de balance](topic:settings-weighted-barcodes)).
