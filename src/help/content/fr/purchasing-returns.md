1. Cliquez sur l'onglet **Retours fournisseurs**, puis sur **Nouveau retour**.
2. Choisissez le **Fournisseur**, puis la **Réception** d'origine.
3. Dans la colonne **Retour**, saisissez le nombre d'unités renvoyées (au maximum la quantité **Retournable**).
4. Indiquez le **Motif** et, si le fournisseur en a donné un, le numéro d'**Autorisation de retour (RMA)**.
5. Cliquez sur **Enregistrer le retour**.

> **Astuce :** les unités retournées sortent du stock de l'emplacement de réception. Un avoir fournisseur de leur valeur est créé automatiquement et réduit ce que vous devez.
